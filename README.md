A clean, responsive blog web application built with **Django**, featuring user authentication, article management, tags, categories, search functionality, and rich template layouts.

---

## 🌟 Key Features

- **✍️ Article Publishing**: Create, edit, publish, and archive blog posts with rich text formatting.
- **🏷 Categories & Tags**: Organize articles by topic for easy navigation.
- **🔍 Content Search**: Search bar for articles and post filtering.
- **💬 Comments & Engagement**: Reader commenting system on individual articles.
- **🎨 Responsive UI**: Clean HTML5/CSS3 templates for mobile and desktop viewing.

## ⚙️ Quick Start

1. **Clone & Setup:**
   ```bash
   git clone https://github.com/Juravoyev/blog_site.git
   cd blog_site
   
   python -m venv .venv
   source .venv/bin/activate  # On Windows: .venv\Scripts\activate
   pip install -r requirements.txt
   ```

2. **Database & Migrations:**
   ```bash
   python manage.py migrate
   ```

3. **Start Development Server:**
   ```bash
   python manage.py runserver
   ```
   Open `http://127.0.0.1:8000/` in your browser.
